# 我的世界地图

这是我个人为了**陪小朋友们一起玩《我的世界》**而创建的地图汇总目录。

收录的地图都是基岩版（Bedrock），为多人一起玩而设计：规则尽量对小朋友友好，内容尽量热闹好找。其中**有些地图的内容，是小朋友们自己想出来的点子**，我负责把它们做进地图里——所以每张地图都带着孩子们的想法在进化。

## 地图目录

| 地图 | 简介 | 版本 |
|---|---|---|
| [小朋友广场 Kids Plaza](小朋友广场-KidsPlaza/) | 出生在安全的小镇广场，商店装备随便拿（黑豆请客），全图箱子自动补货；镇外有山海农场和三座主题小岛可以坐船探险 | v3.22 |

新地图做好后会继续往这个目录里加。

## 说明

- 适用版本：基岩版（Windows / 安卓 / iOS），每张地图的最低版本见各自的说明
- 下载方式：进入地图文件夹，下载 `.mcworld` 文件，打开即自动导入游戏
- 个人家庭游玩可自由分享，请勿用于商业用途
