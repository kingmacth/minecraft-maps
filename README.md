# 我的世界地图 · Minecraft Maps

这是我个人为了**陪小朋友们一起玩《我的世界》**而创建的地图汇总目录。

收录的地图都是基岩版（Bedrock），为多人一起玩而设计：规则尽量对小朋友友好，内容尽量热闹好找。其中**有些地图的内容，是小朋友们自己想出来的点子**，我负责把它们做进地图里——所以每张地图都带着孩子们的想法在进化。

A personal collection of Minecraft maps I create **to play together with the kids**.

All maps are for the Bedrock Edition and designed for group play: kid-friendly rules, and content that is lively and easy to find. **Some of what is in these maps was dreamed up by the kids themselves** — my job is to build their ideas into the world, so every map keeps evolving with their imagination.

## 说明 · Notes

- 适用版本：基岩版（Windows / 安卓 / iOS），每张地图的最低版本见各自的说明
- 下载方式：进入地图文件夹，下载 `.mcworld` 文件，打开即自动导入游戏
- 个人家庭游玩可自由分享，请勿用于商业用途

- Platform: Bedrock Edition (Windows / Android / iOS); see each map's own README for its minimum game version
- To play: open a map folder, download the `.mcworld` file, and open it — the game imports it automatically
- Free to share for personal and family play; please do not use commercially
